# Security and data handling

This repository is a static GitHub Pages front end. It does not include a server, authentication system, database, payment processing, or secure document storage. The MFS and product-lab save features store illustrative configuration in the visitor’s own browser storage; JSON export is generated locally. The contact form opens the visitor’s email application and does not submit data to a MezX server.

Do not enter real customer records, account credentials, confidential financial information, personal data, or regulated records into these demonstrations. Before production use, add a reviewed backend, access controls, encryption, retention policy, logging, backups, privacy notices, security testing, and appropriate legal/compliance review.
